Sample case studies

These are illustrative examples of how I approach typical projects. They describe the method, not confidential employer work.

Cleaning messy sales exports with Python

Problem
Monthly exports from several systems had duplicate orders, missing values and mixed date formats, so reports disagreed.
Approach
Wrote a repeatable Python script to standardize formats, remove duplicates and flag gaps, then checked totals against the source systems.
Result
One clean, documented dataset that feeds every report, with a short log of anything that needed manual review.

Building a star-schema model in Power BI

Problem
Reports were built on wide, flat tables, so the same KPI was calculated differently in each dashboard.
Approach
Split the data into fact and dimension tables, added a shared date table, and wrote the KPIs once as DAX measures in a semantic model.
Result
Consistent numbers across reports, faster visuals, and a model that new dashboards can reuse.

Monitoring refreshes and data quality

Problem
Stakeholders found out about stale or broken reports before the analytics team did.
Approach
Tracked refresh outcomes per dataset and added SQL checks for row counts and nulls, shown on a simple status dashboard.
Result
Failures get spotted and fixed early, and stakeholders can see when each report was last updated.
